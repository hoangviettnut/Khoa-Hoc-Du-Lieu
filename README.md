# Các bước hướng dẫn chạy code
Bước 1: Tải 4 file analysis.ipynb data_pipeline.py, repuirements.txt, csv.zip và giải nén về máy cho vào 1 folder 

Bước 2: Tạo môi trường ảo bằng lệnh ```python -m venv venv```

Bước 3: Chạy lệnh  ```.\venv\Scripts\activate``` để kích hoạt môi trường ảo 

Bước 4: Chạy lện pip ```install -r repuirements.txt``` để tải các thư viện cần thiết 

Bước 5: Sau khi tải xong chạy lệnh ```python data_pipeline.py``` để tiến hành chuẩn hóa và làm sạch dữ liệu điểm thi thô

Bước 6: Vào file analysis.ipynb lựa chọn Kernel chạy là môi trường ảo venv

Bước 7: Bấm Run All để chạy toàn bộ các khối lệnh tính toán phổ điểm và xuất các biểu đồ trực quan.
